get next postfix item;

pop the stack to x;
pop the stack to y;
perform y operator x;
push the results onto the stack;

pop the stack to x;
perform operator(x);
push the results onto the stack
}

Converting Infix to Postfix
• Convert A + B * C to postfix form:
A + B * C Infix Form
A + (B * C) Parenthesized expression
A + (B C *) Convert the multiplication
A (B C *) + Convert the addition
A B C * + Postfix form
Rules:
1. Parenthesize
from left
to
light,
higher
precedence
operators parenthesized first.
2. The sub-expression (part of expression),
which has been
converted into postfix, is treated as single operand.
3. Once
the
expression
is
converted
to
postfix
form,
remove the parenthesis.

===== PAGE 35 =====
35
Steps
1. Operands immediately go directly to output
2. Operators are pushed into the stack (including parenthesis)
▪
Check to see if stack top operator is less than current operator
▪
If the top operator is less than, push the current operator
onto stack
▪
If the top operator is greater than the current, pop top
operator and append on postfix notation, push current
operator onto stack.
▪
If we encounter a right parenthesis, pop from stack until we
get matching left parenthesis. Do not output parenthesis.
Algorithm to Convert Infix to Postfix
Precedence Priority of operators:
▪
Priority 4: ‘(‘ - only popped if a matching ‘)’ is found.
▪
Priority 3: All unary operators (- , sin, cosin,….)
▪
Priority 2: / *
▪
Priority 1: + -
